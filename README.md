# Landasan Teori
**1. Pengertian Struktur Data** 

Struktur data merupakan cara menyimpan, pemgolahan, pengorganisasian, dan pengurutan data didalam komputer agar dapat dimanfaatkan kembali dengan efisien. Sedangkan data adalah fakta mentah yang belum memiliki arti (Zakaria & Prijono, 2006)(A.S & Shalahuddin, 2016). Pengertian data menurut ahli: Data adalah fakta yang dikumpulkan, disimpan dan diproses oleh sistem informasi (Romney & Steinbart, 2014) (Application et al., 2018). Data adalah fakta atau obervasi mentah yang biasanya mengenai fenomena fisik atau transaksi data (Indrajani, 2015).

Beberapa pengertian struktur data menurut ahli: Struktur data adalah abstraksi model/penyimpanan;") engaturan/susunan data dalam memori atau RAM komputer atau koleksi dari satu variable yang dapat dinyatakan dengan nama, dengan sifat setiap variable dapat memiliki tipe yang berlainan (Setyaningsih, 2012)(Ikhwan et al., 2015). Struktur data adalah model logika atau matematik yang secara khusus mengorganisasikan data. Sebuah model harus dapat mencerminkan keterhubungan data dengan dunia nyata dan bentuknya sederhana (Setyaningsih, 2012).
